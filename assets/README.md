# Ассеты прототипа «Эллада»

Игра горизонтальная, как оригинал: базовый экран 1280×720 (16:9).

Кладите PNG с прозрачностью в эту папку. Имя файла должно совпадать точно.
Всё, чего здесь нет, игра рисует заглушкой. Полный список с отметкой «есть / нет»
показывается в самой игре: карта уровней → «Ассеты».

Размеры указаны для исходника в двойном размере (на экране вдвое меньше).

## Клетки и поле
- cell_normal.png: ширина 256, обычная клетка (шестиугольник с плоскими гранями сверху и снизу; толщину снизу можно оставить, высота любая)
- cell_gold.png: ширина 256, золотая плитка
- bg_episode.png: 2560×1440, горизонтальный фон эпизода за полем

## Фишки (160×160, фишка по центру, с запасом под тень)
- chip_horse.png: конь, зелёный круг
- chip_amphora.png: амфора, синий квадрат
- chip_bull.png: бык, красный треугольник
- chip_helmet.png: шлем, жёлтая звезда-ромб
- chip_mask.png: маска, светлая табличка
- chip_lyre.png: лира, фиолетовый щит
- chip_<имя>_selected.png: необязательно, вид фишки в цепочке (иначе рисуется свечение)

## Особые фишки
- coin.png: 140×140, монета без цифры (номинал 1–3 игра пишет сама)
- bolt_v.png, bolt_d1.png, bolt_d2.png: 160×160, молнии по вертикали и двум диагоналям
- bolt_star.png: 160×160, молния во все стороны
- bolt_area.png: 160×160, удар по площади
- gem_red.png: 150×150, красный самоцвет

## Препятствия (220×220)
- mono_2.png: монолит целый
- mono_1.png: монолит с трещинами
- stone_hades.png: камень из Аида
- rope.png: верёвка, кладётся поверх фишки

## Интерфейс
- caryatid.png: 300×900, кариатида, держащая колонну-таймер (воду в колонне рисует игра поверх)

## Портреты (256×256, круглая обрезка делается кодом)
