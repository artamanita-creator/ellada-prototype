# Эллада

Играбельный прототип казуальной игры «три в ряд» на шестиугольном поле: фишки собирают цепочками, протягивая палец по соседним одинаковым. Это мой фанатский ремейк-переосмысление игры Heroes of Hellas (Alawar), которую я любила в детстве. Весь арт, интерфейс и код новые. Оригинальная графика, музыка и название не используются.

Проект для портфолио 2D-художника: я рисую фишки, панели, интерфейс и экраны, а прототип показывает, как они работают в живой игре.

## Что есть
- 6 уровней одного эпизода: золотые плитки, монеты и монолиты, красные самоцветы, молнии, верёвки, камни Аида
- цепочки из 5+ фишек дают монету, из 10+ молнию (5 видов удара)
- помощники Зевс, Икар и Ясон со своими умениями
- постройка дворца за монеты с выбором вариантов
- ограничение ходами или временем

## Как запустить
Откройте `index.html` в браузере или через GitHub Pages.

## Арт
Пока на месте графики заглушки. Готовые PNG кладутся в `assets/` с именами из [assets/README.md](assets/README.md) и сразу заменяют заглушки.
